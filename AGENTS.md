# NEBA Café — Development Guidelines

This repository contains the frontend codebase for the **NEBA Café Ordering & Management System**.

## Development Rules

- Preserve all existing customer ordering, cart, checkout, tracking, and staff/admin workflows.
- Maintain the approved NEBA Café visual identity (Red `#C8102E`, White, Charcoal `#1F2937`).
- Keep all TypeScript types valid and pass `npm run build` and `npx tsc --noEmit`.
